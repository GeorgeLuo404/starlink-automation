# 后台使用说明

后台地址：`https://你的域名/admin`
（本地开发：<http://localhost:3000/admin>）

---

## 登录

默认账号见 `.env` 的 `ADMIN_EMAIL` / `ADMIN_PASSWORD`。
**上线前必须修改**：

```bash
ADMIN_EMAIL=admin@your-domain.com ADMIN_PASSWORD='强密码' pnpm admin:create
```

登录状态保存在 HttpOnly Cookie 中，有效期 7 天。

---

## 后台菜单

左侧菜单分三组，「网站内容」与前台顶部导航的顺序和名称完全一致，想改网站哪一页，就点同名的菜单：

| 分组 | 菜单 |
| --- | --- |
| 概览 | 仪表盘、客户询盘 |
| 网站内容 | 首页、业务能力、项目案例、新闻动态、现场图库、资料下载、关于我们、联系我们 |
| 资源与设置 | 媒体库、站点设置 |

- 首页、关于我们、联系我们会在菜单里展开各自的栏目（按页面从上到下的顺序），点栏目直接打开对应的编辑区；
  已在该页面时，再点一次页面名可以收起或展开栏目列表。
- 左上角的 ▢ 按钮（或 ⌘B / Ctrl+B）把侧栏收起成图标，鼠标悬停图标会显示名称；收起状态会被记住。
- 手机上点左上角的按钮打开菜单。
- 顶部一行显示当前位置，例如「首页 › 服务流程」。

网站上看得到的业务内容都在后台修改，不需要改代码；按钮、表单提示等界面文字仍在代码中。

## 媒体库：一切素材的起点

**建议的操作顺序：先上传素材，再写内容。**

1. 左侧「资源与设置 → 媒体库」
2. 把图片/视频/文档**拖进上传区**（支持多选，会显示进度）
3. 上传完成后鼠标悬停缩略图 → 点**复制图标**拿到链接
4. 到文章/案例/图库的编辑页，把链接粘贴进「封面图片」输入框

也可以用「封面图片」旁边的**上传**按钮直接上传，效果一样。

**没有照片时**：业务能力、项目案例、新闻的「封面图片」留空，或仍是初始化写入的 `/media/….svg`，
前台显示的就是对应题材的线稿占位图，版式与真实照片完全相同。拍到现场照片后，在该条目上传封面
替换这个地址即可，无需改代码。建议照片横向、比例约 16:10，宽度不小于 1600 像素。

**限制**：单文件 200MB（`MAX_UPLOAD_MB` 可调）；支持 jpg/png/webp/gif/avif/svg、
mp4/webm/mov、pdf/zip/docx/xlsx/pptx/csv/txt。

## 列表页

业务能力、项目案例、新闻动态、资料下载的列表页都支持：

- **搜索**：按标题（及行业等文字列）即时筛选
- **状态筛选**：只看已发布 / 草稿 / 已归档
- **排序**：点列标题切换升序 / 降序（年份、发布日期、阅读数等）
- 超过 10 条时出现分页，可选每页 10 / 20 / 50 条
- **页头文字**：右上角的「页头文字」按钮，修改前台该列表页顶部的眉标、标题和说明（说明同时用作搜索引擎摘要）。
  现场图库也有这个按钮。

案例与文章的列表还会显示封面缩略图和「影像」数量。

## 封面与影像（案例、新闻、业务能力）

案例、文章和业务能力的编辑页都有「封面与影像」一节：

- **封面图片**：用于列表卡片、首页与分享卡片。留空时自动使用下方第一张图片（或第一个视频的封面）。
- **图片与视频**：可以混合添加，最多 30 项，详情页顶部按顺序轮播（每 5 秒自动切换，可左右箭头、滑动或点缩略图切换；
  鼠标悬停时暂停，访客手动切换或播放视频后停止自动切换）。没有任何图片和视频时，详情页仍显示封面。
  - **上传图片**：可多选，或直接把文件拖进虚线框；会显示上传进度
  - **上传视频**：建议压缩为 1080p MP4、50MB 以内。可「上传封面」，或播放到合适的画面后点「截取当前帧」
  - **添加 B站 视频**：粘贴视频页链接（`https://www.bilibili.com/video/BV…`，也支持 `b23.tv` 短链接，保存时自动解析）。
    **B站 视频必须上传封面**。外链播放器对未登录 B站 的访客通常画质较低，重点展示的视频建议直接上传 MP4。
- **调整顺序**：按住卡片左上角的把手 ⠿ 拖动；键盘操作为 Tab 到把手 → 空格拿起 → 方向键移动 → 空格放下。
- 每项可填「说明」（电脑上显示在轮播右侧的缩略图列表里，手机和文章页显示在轮播下方）；图片还可填「替代文本」（给读屏软件，留空则用说明）。
- 卡片右下角的「设为封面」会把该图片（或视频封面）填进封面图片。
- **预览**：点任意缩略图（或卡片上的 ⤢ 按钮）会弹出大图 / 播放视频，弹窗里可用 ← → 切换。
  封面图片同样可点缩略图预览；把新文件拖到封面卡片上即可替换。
- 上传未完成时无法保存，等进度条走完即可。

## 页面文字（首页、关于我们、联系我们）

这三页没有「列表」，而是一段段固定的栏目，按**前台从上到下的顺序**列在左侧菜单的页面名下面，点哪个改哪个
（侧栏收起或在手机上时，栏目显示在编辑区上方的一排标签里）：

- **每个栏目单独保存**。改过但没保存的栏目，菜单里会出现黄点，标题旁显示「未保存」；
  切换栏目不会丢失修改，带着未保存的修改去别的页面时会先询问。
- **撤销修改**：放弃这个栏目还没保存的修改。
- **恢复默认**：删除这个栏目保存过的文字，网站改回最初的默认文字。标题旁的「默认内容 / 已自定义」显示当前状态。
- **列表项**（服务流程的步骤、发展历程的里程碑等）：按住左侧把手 ⠿ 拖动排序（键盘：空格拿起、方向键移动、空格放下），
  点标题行展开编辑，右侧垃圾桶删除，底部「添加」新增。项目多时默认收起，方便看清顺序。
- **每行一个**的输入框（关键词、交付物、资质等）：一行就是一项，空行会被忽略。
- **强调文字**：标题里要用主色显示的那几个字，必须与标题中的文字一模一样；留空则不强调。
- 输入框右上角的 `12 / 40` 是字数提示，超过上限无法保存——上限是为了保证版式不被撑坏。
- 右上角「在前台查看」会在新标签页打开该页面，保存后刷新即可看到效果。

### 服务流程的插图

每个步骤右侧的线稿动画在步骤卡片的「插图」里选择：点「选择插图」，从插图库里点一张即可。

- 插图库分两组：**流程动画**（现场勘察、方案设计、电气设计、程序开发、现场调试、交付培训）和
  **设备与场景**（PLC 控制柜、工业机器人、视觉检测线、热压机、产线布局、节拍分析等 16 张，循环描线出现）
- 插图跟着步骤走：调整步骤顺序后，每一步仍是自己的插图
- 新增的步骤默认「无插图」，此时文字占满整行
- 暂不支持上传自己的图片，以保持全站线稿风格统一；需要新的插图时，由开发加入插图库后即可在这里选择

### 品牌平台

首页「支持的品牌与平台」一栏，滚动展示我们能对接的 PLC、机器人等品牌。这里只说明
「我们支持这些平台」，不代表合作或授权关系，前台也会附上一句商标声明。

- **新增 / 编辑**：品牌列表右上角「新增品牌」或每行的编辑按钮，在弹窗里填写名称、品牌中文名并上传 Logo；
  弹窗底部的「首页效果」就是前台的实际样子
- **Logo**：用**透明背景**的 SVG 或 PNG。前台会把所有 Logo 统一显示为白色单色，
  带白底或色块底的图片会变成一个白色方块。没有 Logo 时直接显示名称文字
- **排序**：拖动每行左侧的手柄（键盘：Tab 到手柄，空格拿起、方向键移动、空格放下），松手即保存
- **显示开关**：关闭后首页不再展示该品牌，但记录和 Logo 都保留，随时可以再打开
- 默认的 12 个品牌 Logo 放在 `public/brands/`，来源见 `docs/BRAND-LOGOS.md`；
  拿到品牌方的官方素材后，直接在弹窗里拖入新文件替换即可

## 业务能力

- 「图标」下拉框决定首页卡片上的图形（Cpu / Bot / Ruler / BatteryCharging / Flame）
- 「服务内容清单」每行一条
- 「交付物清单」每行一条
- 「常见问题」每行一条，格式：`问题|答案`
- 「封面与影像」用法同上文；封面显示在详情页顶部，图片与视频显示在详情页中部的「现场影像」区（没有时不显示该区域）
- **排序**决定前台展示顺序

## 项目案例

- 「关键指标」每行一条，格式：`数值|说明`

  ```
  -20%|节拍时间
  99.6%|设备综合效率
  ```

- 「服务范围」每行一条
- 「项目地点」「交付年份」会显示在案例详情页的右侧信息栏
- 勾选「推荐到首页」后会出现在首页案例区
- 现场照片与视频见上文「封面与影像」

## 新闻动态

「网站内容 → 新闻动态 → 新建文章」

- **标题必填**
- **URL 别名**留空会根据标题自动生成
- **正文标记**（不使用 Markdown 库，只支持以下轻量语法）：

  ```
  ## 二级标题
  ### 三级标题
  - 无序列表项
  1. 有序列表项
  > 引用
  **加粗**   `行内代码`
  ```

  段落之间**空一行**。多个网段会被合并为一个 `<p>`，用单个换行即可换行。
- **状态**：草稿不会出现在前台；已发布才会。
- **精选**：勾选后会出现在首页「新闻动态」的推荐位置。

列表页可以直接点「发布 / 下架」快速切换状态。

## 现场图库

- 「相册」是前台的筛选维度，例如 `产线现场` / `设备实拍` / `团队风采`
- 类型选「视频」时，除了封面图还需要填「视频文件」
- 前台灯箱支持键盘 ← → 切换、Esc 关闭

## 资料下载

两种做法：

1. **先上传文件**（媒体库或表单里的上传按钮）→ 地址自动填入
2. **不上传**：留空时，前台点击下载会**动态生成一份占位 PDF**（方便演示）

- 「文件大小」用于前台显示，上传后按实际字节数填写
- 「下载次数」由系统自动统计
- 勾选「下载前需要填写联系方式」会先弹窗收集姓名/电话，再开始下载，
  收集到的信息会进入「客户询盘」（来源标记为 `download`）

## 关于我们

用法见上文「页面文字」。栏目依次为：页头、公司简介（两段文字与配图，配图留空则用默认线稿）、
关键数据、做事方式、发展历程、团队构成、资质与认证。

公司全称、成立年份、地址和邮箱显示在「公司简介」旁边，它们在「站点设置」中修改（全站共用）。

## 联系我们

- **页头与表单**：页面标题、说明（同时用作搜索引擎摘要）、表单标题与说明
- **补充信息**：电话、邮箱、地址下方的两行（默认是工作时间与紧急支援），内容留空的那一行不显示

电话、邮箱、地址在「站点设置」中修改。

## 客户询盘

- 顶部按状态筛选：新询盘 / 跟进中 / 已完成 / 垃圾信息
- 每条可以改状态并写**跟进备注**
- 网站页脚的订阅、资料下载留资也会汇总到这里（看「来源」标签）
- 左侧菜单「客户询盘」上的黄色角标 = 待处理（NEW）数量

## 站点设置

全站共用的信息，保存后前台自动刷新。

| 项 | 说明 |
| --- | --- |
| 公司全称 / 简称 | 全称显示在页脚版权、「关于我们」和首页标题；简称接在其他页面的浏览器标题后面 |
| 成立年份 | 显示在「关于我们」 |
| 页脚简介 | 页脚 Logo 下方的一段话 |
| 业务电话 / 邮箱 | 显示在页脚、联系页与关于页 |
| 公司地址 | 显示在页脚、联系页与关于页 |
| ICP 备案号 / 公安备案号 | 备案通过后填写，页脚自动显示并链接到对应的查询网站；**留空则页脚不显示** |
| 首页标语、网站描述、关键词 | 搜索结果与分享卡片中的文字；关键词用逗号分隔 |
| 统计代码 ID | 留空则不加载任何统计脚本 |

## 日常维护建议

| 频率 | 事项 |
| --- | --- |
| 每周 | 处理「客户询盘」，把已完成的改为「已完成」 |
