# 品牌标识来源 / Brand logo sources

首页「支持的品牌与平台」默认使用的 Logo。商标归各自权利人所有，仅用于说明我们可对接的
产品平台，不代表合作或授权关系。拿到品牌方官方素材后，可在后台「首页 → 品牌平台」中直接替换。

All files were minified with SVGO; the colours are untouched (the site renders them
single-colour with a CSS filter).
